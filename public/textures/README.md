# Wrinkled paper

`wrinkled-paper.png` was generated with the built-in imagegen tool for FourPataka's paper studio design on 2026-09-30. The source is copied into this project so both browser and desktop builds can use it offline. It contains no external photo assets.

Final generation prompt:

> Use case: photorealistic-natural. Asset type: website material texture. Create a square, edge-to-edge texture photograph of warm ivory cream drawing paper that has been lightly crumpled and flattened again. Fine visible paper fibers, soft organic wrinkle ridges, a few shallow irregular diagonal and crossing creases, subtle diffuse side lighting giving realistic tactile highlights and soft shadows. The entire image is uniformly paper, flat overhead view, no perspective, no sheet edges, no desk or surrounding objects. Pale warm ivory with neutral beige shadows, low contrast but visibly wrinkled, not brown or grungy. This is a repeating UI background behind dark readable ink, with a handcrafted playful notebook feel. No text, no marks, no drawings, no objects, no gradients other than natural paper relief, no watermark. Generous open areas between wrinkles.
