## FourPataka

FourPataka v0.39.0 is a local browser/Electron music studio with32 signed Fourier harmonics, waveform points/drawing, noise-hit drums, independent instrument copies, five serial pedals, a multi-file score IDE, swing, frozen WAV export and initial source/live-output analysis. Canonical scoreText owns the song; A/B changes retain the clock. M1–M6 are implemented: public module metadata/pedal/preset/engine/feature boundaries, schema5 migration/unavailable recovery, contributor tutorials and CI, GPL-3.0-only, operational safeguards and durable contributor-preview distribution. Chamber acoustics, WAV-to-instrument reconstruction, phaser/chorus/reverb, further notation/analysis and manual listening/device/accessibility checks remain future work. Start with docs/knowledge/TASK_GUIDE.md; historical verification is in IMPLEMENTATION_STATUS.md.
